# 🌸 Floerella – Flower Shop Website

Floerella is a responsive flower shop website designed to provide a simple and elegant online shopping experience. It allows users to explore flower collections, browse products, and manage their shopping preferences through a clean interface.

## ✨ Features

- Responsive and user-friendly interface
- Home page with featured collections
- Product browsing and shopping page
- Wishlist functionality
- Shopping cart
- About and Contact pages
- Clean and consistent UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Pages

- Home
- Shop
- Wishlist
- Cart
- About
- Contact

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Anchalcloud/Floerella.git
   ```

2. Open the project folder.
3. Run `index.html` in your browser.

## 🎯 Project Purpose

This project was developed to strengthen frontend development skills and practice building responsive, user-friendly web interfaces.
